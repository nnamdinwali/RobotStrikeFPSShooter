# Robot Strike FPS Shooter

Standalone Unity WebGL build of **Robot Strike FPS Shooter**.

## Run locally

Serve this directory through a web server; opening `index.html` directly with `file://` is not supported by Unity WebGL.

```bash
python3 -m http.server 8080
```

Then open <http://localhost:8080> in a browser.

The original Unity WebGL directory structure is preserved, including the `Build/` payload and `TemplateData/` assets.
